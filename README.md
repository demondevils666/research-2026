# Город больше своих границ

Типы локальных экономик России по тратам жителей: динамическая атрибутированная сеть муниципальных образований (МО).
Онлайн-конкурс СберИндекса 2026, номинация «Кластеризация». Автор: Дмитрий Юшков.

- **Лендинг** (карта типов и ребер сети, поиск МО, паспорт, двойники): https://demondevils666.github.io/research-2026/
- **Методологический отчет (PDF):** краткая версия на 7 страниц — [docs/report_short.pdf](docs/report_short.pdf),
  полный отчет — [docs/report.pdf](docs/report.pdf)

## Коротко
- Сеть из 2 016 МО: узел описан структурой и уровнем трат жителей по данным СберИндекса
  за 24 месяца, ребро соединяет соседей по границе, вес тем больше, чем ближе центры по дороге.
- Совместная кластеризация признаков и сети (KEFRiN) дает **6 типов местных экономик**: от крупных городов до
  аграрных районов, где доля маркетплейсов выше всего.
- **Главная находка.** У 76% районов вокруг городов с общим центром («бубликов») профиль трат ближе
  к своему городу, чем к районам своего региона (88 пар); у обычных соседних районов — у 51%.
  Сильнее всего это у столиц регионов (20 из 20 против 42%); у остальных городов различие по профилю
  незначимо (66% против 55%; разбивка — по 64 парам полной панели). Росстат считает зарплату по месту работы, а СберИндекс траты —
  по месту жительства, поэтому пригород, сельский по статистике, живет как город.
- **Проверка переписью 2010 года** (20 регионов): из «бубликов» ездят на работу в другой населенный пункт
  на 18,1 п. п. чаще, чем из обычных соседей города (p < 0,001).
- **С отчетом лаборатории СберИндекса это согласуется:** все 4 пригорода Дальнего Востока
  из ее отчета попали в наши «городские» типы. Районов всего 4, и у 2 из них города нет в данных, поэтому это сверка,
  а не строгая проверка.
- **Функциональные города.** В 149 городах официально 32,7 млн жителей, вместе с «бубликами» —
  36,2 млн, вместе с кандидатами в «скрытые спутники» — до 40,3 млн (спутников перепись не подтверждает, поэтому это оценка сверху).
- **Вывод о методе.** Тип задает поведение жителей, сеть почти не меняет типы: при выбранном весе сети
  α = 0,6 разбиение почти совпадает с разбиением только по тратам (ARI 0,97), а при большем весе типы перестают
  воспроизводиться; от выбора правила ребра типы меняются умеренно. Это вывод для нашей постановки (KEFRiN, сеть
  соседства, 6 типов на всю страну).

## Три вопроса конкурса
1. **Что именно найдено?** Шесть типов местных экономик и эффект «город больше своих границ»: пригороды живут как свой
   город, хотя статистика по месту работы их не видит (отчет, разделы 2–3).
2. **Почему этому можно доверять?** Проверка данными, которые в расчет не входили: Росстат (тип сравниваем с базой —
   группами по одному уровню трат) и перепись 2010 года; с ними согласуется отчет лаборатории СберИндекса. Контрольные группы
   и перестановочные тесты; реализации сверены с кодом авторов и библиотекой жюри. Отрицательные результаты показаны:
   налоговый след, скрытые спутники в переписи, значимость различий методов (разделы 2, 5, 8).
3. **Как это можно использовать дальше?** Сверять зарплату Росстата с тратами СберИндекса, чтобы не принять пригород
   за бедное село; сравнивать МО с похожими из других регионов («двойниками»): искать у них применимый опыт и сравнивать
   рост трат (раздел 9, поиск на лендинге).

## Как воспроизвести
Нужны Python 3.11, [uv](https://docs.astral.sh/uv/) и `bsdtar` (`apt install libarchive-tools`) для распаковки `.rar`.
PDF отчета печатает Chromium через Playwright (`playwright install chromium`); без него остаются md и html.
Окружение ставится из `requirements.lock.txt` — точные версии всех пакетов. torch для CPU берется с индекса PyTorch,
поэтому uv нужен флаг `--index-strategy unsafe-best-match`: остальные пакеты он берет с PyPI, как pip.

```bash
uv venv .venv --python 3.11
uv pip install --python .venv/bin/python --index-strategy unsafe-best-match -r requirements.lock.txt
.venv/bin/python scripts/build_ca_bundle.py   # сертификаты (TLS не отключается)
.venv/bin/python scripts/download_data.py     # сырые данные в data/raw/, сверка sha256 с data/raw/MANIFEST.json
.venv/bin/python scripts/run_all.py           # анализ, рисунки, отчет, лендинг, тесты
```

- `download_data.py` сверяет каждый файл с `data/raw/MANIFEST.json` по sha256. Если источник обновил файл, скрипт
  останавливается: на другой версии данных числа отчета могут не совпасть. `--verify` проверяет уже скачанные файлы без сети.
- Тесты без данных и без кода авторов: `.venv/bin/python -m pytest tests` — 31 проходит, 10 пропускаются (им нужны
  `data/processed/` после `run_all.py` или `third_party/` после `scripts/fetch_external.py`). После полного прогона проходят все 41.

Последний полный прогон: 78 мин на 4 CPU, пиковая память шага —
до 1,6 ГБ. Самые долгие шаги: `scripts/methods_seeds.py` (25 мин), `scripts/canus_tuning.py` (14 мин).
Повторный прогон дает те же файлы байт в байт, кроме полей времени счета (`time_s`, `timing_s`, `speedup`) и даты создания PDF.
Продолжить с шага: `scripts/run_all.py --from interpret`.
