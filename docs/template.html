                    Как воспроизвести

                    uv venv .venv --python 3.11
uv pip install --python .venv/bin/python --index-strategy unsafe-best-match -r requirements.lock.txt
.venv/bin/python scripts/build_ca_bundle.py   # сертификаты (TLS не отключается)
.venv/bin/python scripts/download_data.py     # сырые данные в data/raw/
.venv/bin/python scripts/run_all.py           # анализ, рисунки, отчет, лендинг, тесты

                    Все параметры — в configs/base.yaml, seed фиксирован. Время и пиковая память каждого шага записываются в outputs/run_timings.json.

                    Все числа на странице посчитаны кодом из репозитория. Шрифты Onest и Golos Text — SIL OFL 1.1.
